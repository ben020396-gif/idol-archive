# IDOL ARCHIVE

K-POP Group & Music Database

## 專案簡介

IDOL ARCHIVE 是一個 K-POP 偶像知識庫網站，
用來整理韓國偶像團體、成員、音樂作品及舞台紀錄。

第一個收錄的團體為 ILLIT。

## 網站特色

- K-POP 團體資料
- 偶像成員介紹
- 音樂作品整理
- 舞台紀錄
- 簡約日系網站設計
- 支援手機及電腦瀏覽

## 使用技術

- HTML
- CSS
- JavaScript
- JSON
- GitHub Pages

## 專案規則

本專案使用 AGENTS.md
作為 AI 開發及修改網站的主要規範。

新增團體及內容時，
必須遵守既有的資料格式與設計風格。
